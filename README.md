# Тестирование фильтрации недвижимости на Avito

## О проекте

Учебный проект по функциональному тестированию фильтров поиска недвижимости на сайте Avito.

В рамках проекта проведено тестирование поиска недвижимости в Санкт-Петербурге при выборе типа сделки «Купить».

## Цель тестирования

Проверить корректность работы фильтров и соответствие результатов поиска заданным параметрам при покупке недвижимости в Санкт-Петербурге.

## Область тестирования

В рамках проекта проверялись:

- тип жилья;
- количество комнат;
- стоимость;
- площадь;
- этаж;
- расстояние до метро;
- совместная работа нескольких фильтров;
- изменение установленных фильтров;
- удаление установленных фильтров;
- обработка некорректно заданных диапазонов.

## Виды проверок

В проекте выполнены позитивные и негативные проверки, а также проверки комбинации фильтров и изменения параметров фильтрации.
