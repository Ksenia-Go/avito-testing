# Avito Testing

Учебный проект по тестированию фильтрации объявлений в разделе «Недвижимость» на сайте Avito.

## О проекте

В рамках проекта проведено тестирование фильтрации объявлений при покупке недвижимости.

Проверены:
- фильтрация по отдельным параметрам;
- совместная работа нескольких фильтров;
- позитивные и негативные сценарии;
- сброс выбранных фильтров.

## Результаты тестирования

В рамках проекта было разработано и выполнено 7 тест-кейсов для проверки функциональности фильтрации объявлений в разделе «Недвижимость».

Проверены следующие сценарии:
- фильтрация по типу жилья «Новостройка»;
- фильтрация по расстоянию до метро;
- фильтрация по стоимости объекта;
- совместная работа нескольких фильтров;
- фильтрация по этажу;
- негативный сценарий с некорректным диапазоном стоимости;
- очистка выбранного фильтра.

Все выполненные тест-кейсы завершились успешно (Status: Pass).
